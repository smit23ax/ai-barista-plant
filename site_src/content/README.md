# Owner-supplied website content

Each file below fills one item of the release checklist. While a file is missing or empty, the page shows a "To do" box,
and `FINAL=1` builds refuse to run.

| File | What goes in it |
|---|---|
| `youtube_video_id.txt` | The YouTube video id only (the part after `watch?v=`) |
| `youtube_transcript.txt` | YouTube's auto-generated transcript, pasted **unedited** (⋯ → Show transcript → copy all) |
| `youtube_comments_posted.txt` | Link to the video after the practice transcript and AI critique are posted as public comments |
| `members.html` | Each group member's name and contribution (HTML list or table) |
| `learnings.html` | What we learned, in our own words (HTML paragraphs) |
| `presentation_dates.html` | The two in-class presentation dates |
| `streamlit_cloud_check.txt` | Date and result of rebooting the Streamlit Cloud app on main |
